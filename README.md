# SMC Trading Journal — Android APK

Natywne opakowanie Android dla lokalnego Trading Journal SMC (NQ/MNQ).

## Funkcje
- trade: data, NQ/MNQ, TP/SL/BE, confluencje, rating 1–5, notatka
- statystyki: win rate, TP/SL/BE, equity curve
- historia z usuwaniem
- Friday Review (5 pytań)
- dark mode
- dane zapisane lokalnie w WebView/localStorage
- aplikacja nie wymaga internetu

## Budowanie APK na GitHub
1. Wrzuć całą zawartość projektu do repozytorium GitHub.
2. Wejdź w Actions → Zbuduj APK.
3. Po zielonym buildzie pobierz artifact `SMC-Trading-Journal-APK`.
4. Rozpakuj i zainstaluj `app-debug.apk` na Androidzie.
